# Mitgelieferte Schrift

**Space Grotesk**, latin-Teilmenge (U+0000–00FF, deckt die deutschen Umlaute ab), 22 KB.

- Bezogen von Google Fonts (v22), Projekt: https://github.com/floriankarsten/space-grotesk
- Lizenz: SIL Open Font License 1.1, siehe `OFL.txt`

Sie liegt hier im Repo und wird vom eigenen Webdienst ausgeliefert, **nicht** von Google Fonts.
Damit funktioniert die Oberflaeche ohne Internetverbindung, und es geht keine Anfrage nach
draussen, wenn jemand die Seite oeffnet.

Verwendet wird sie nur fuer Ueberschriften und Zahlen. Fliesstext bleibt die Systemschrift.
